This is a [SCHOOL WEBSITE](https://govt-l-p-school-vengody.vercel.app/) built using [Next.js](https://nextjs.org), bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

Tech stack used: 
- OpenAI
- TS
- Next.js
- Clerk for auth
- Neon as database
- Drizzle ORM
- Supbabase for storing images
- Nodemailer for mailing
- Shadcn 

About the app:
- Volunteered: Built a Full-Stack student management web app for Govt L P School, Vengodi(250 pupils).
- Implemented secure authentication with Clerk, enabling admin-only approval/rejection of teacher sign-ups.
- Designed a PostgreSQL database (Neon) with Drizzle ORM for CRUD of students, teachers, and exam grades.
- Integrated OpenAI API to generate student performnace reports and improvement tips based on exam grades.
- Facilitated downloadable PDFs containing student details, grades, and AI feedback for distributing to parents.

**I will be adding more features to this website soon.**
